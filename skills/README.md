# Skills

Raccolta di skill vendorate nel repo per gli agenti di sviluppo. Vedi `AGENTS.md` alla radice per il routing per task e `SOURCES.md` per fonti e licenze.

## Indice

### Design & UI review
- `better-interface` — review completa di una schermata: accessibilità, layout, tipografia, colore, polish
- `interface-review` — review mirata di un'interfaccia con report ranzato
- `better-ui` — principi di UI polish
- `better-layout` — layout, spaziature, griglie
- `better-typography` — tipografia
- `better-colors` — colore e contrasto
- `better-accessibility` — accessibilità

### Game dev web (canvas 2D, TS vanilla)
- `game-engine` — game loop, input, rendering, fisica 2D su canvas (con asset `2d-maze-game.md` dedicato ai labirinti)
- `game-feel` — juice, feedback, risposta dell'input
- `game-ui-ux` — menu, HUD, schermate di gioco
- `procedural-gen` — generazione procedurale (labirinti)
- `save-systems` — persistenza (localStorage)
- `input-systems` — tastiera e touch/swipe
- `performance-optimization` — prestazioni canvas e loop

### Frontend & testing
- `frontend-design` — progettare interfacce distintive (Anthropic)
- `webapp-testing` — test browser reali (richiede Playwright in locale)
